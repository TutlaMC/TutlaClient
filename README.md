# TutlaClient
**TutlaClient** is a fully featured Minecraft client featuring many utility keybinds, rendering utilities & pvp tools!

---

## ⚙️ Features & Usage

- ⚡ Easy to use
- 🌀 Amazing and Modern UI
- 🛠️ Many modules

### 🕹️ Features

<details>
<summary>🖲️ <b>Modules</b></summary>

<br>

| ⚙️ Category   | 💻 Module        | 📖 Description                                      |
|---------------|------------------|-----------------------------------------------------|
| ⚔️ PvP        | LeaveThisGoBack! | Double click a slot to go back to the previous slot |
| 󰹑  Rendering | ClearWater       | See in water                                        |
| 󰹑  Rendering | FullBright       | See in darkness                                     |
| 󰹑  Rendering | NoFire           | Disables fire from covering your screen             |
| 󰹑  Rendering | NoHurtCam        | Prevents shake when damaged                         |
| 󰹑  Rendering | NoPortalOverlay  | Removes portal overlay                              |
| 󰹑  Rendering | NoPumpkinHead    | Removes pumpkin head overlay                        |
| 󰹑  Rendering | NoViewBob        | Prevents bob while walking                          |
</details>

<details>
<summary>🌀 <b>Key Binds</b></summary>

<br>

| ⌨️ Keybind                                      | 📖 Description                |
|-------------------------------------------------|-------------------------------|
| Open Menu                                           | Open TutlaClient menu |
| Leave                                           | Leave a server with a keybind |
</details>

### 🌀 Default Twists
- `DEFAULT` – Standard manhunt rules
- `PIG_OP_LOOT` – Pigs drop OP loot (only for the speedrunner 🐷💎)
- **More twists coming soon! 🔧**
